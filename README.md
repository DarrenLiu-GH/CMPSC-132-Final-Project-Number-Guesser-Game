Project description:
My program is a number guessing game that uses a class and a couple of functions. The player must create a game session, and then select a difficulty option. Then, they must guess a randomly generated number based on the range given. The program checks to make sure that the player's input is a valid integer in the given range. The player has a limited number of attempts to try to guess the number.

Instructions to run program:
Open a terminal for this program. Type the following command: python -i "number_guesser.py"
Type g = NumberGuesser() to create a game session. Then, type g.diff_select(), and type "easy", "medium", or "hard" to select a difficulty.
Then, type g.game() to start a game session.
Then, type an integer within the given range (inclusive). You will be given feedback regarding if your answer is correct, too high, or too low. You have a limited number of attempts to guess the number.
